# Pradeep Palanisamy — Developer Portfolio

A responsive, light-theme developer portfolio built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — layout, colors, typography and responsive styling
- `script.js` — mobile navigation and current footer year

## Run locally
Open `index.html` in your browser. No build tools or dependencies are required.

## Before publishing
1. Verify your job title and employment dates.
2. Add your education and certifications if you want them shown.
3. Replace the sample project links with the exact GitHub repository URLs.
4. Update project descriptions to reflect completed features accurately.
5. Add a PDF named `resume.pdf` in this folder if you want a resume download link. (The current page does not include a resume button yet.)
6. Review all details and contact links.

## Publish using GitHub Pages
1. Sign in to GitHub and create a new **public** repository named `pradeep-portfolio`.
2. Upload `index.html`, `style.css`, `script.js` and `README.md` to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for the deployment to finish. Your site will be available at:
   `https://YOUR-GITHUB-USERNAME.github.io/pradeep-portfolio/`

If you name the repository exactly `PradeepCodes.github.io`, GitHub Pages can instead publish it at `https://pradeepcodes.github.io/`.
